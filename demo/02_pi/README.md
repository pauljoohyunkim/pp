# 02_pi – Pi Approximation Demo

Leibniz series approximation of π using a loop.

## Files
* `main.pp` – computes and prints π approximation
* `Makefile` – builds `pi_demo`

## Build

```bash
make
```

## Run

```bash
./pi_demo
```

Expected output: an approximation of π ~3.141...

## Clean

```bash
make clean
```
