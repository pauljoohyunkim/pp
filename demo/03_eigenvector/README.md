# 03_eigenvector – Eigenvector Demo

Power method to approximate an eigenvector of a 2×2 matrix.

## Files
* `main.pp` – matrix/vector types, power iteration, printing

## Build

```bash
make
```

## Run

```bash
./eigenvector_demo
```

Expected output: matrix, initial vector, and an approximated eigenvector close to (-2,1).

## Clean

```bash
make clean
```
